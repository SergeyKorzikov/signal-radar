# Радар слабых сигналов

Каждую неделю радар просматривает десятки тысяч свежих статей, репозиториев, моделей и обсуждений
и ищет то, что сейчас находится **на стадии ИИ в 2020–2021 году**: строители уже одержимы,
а мейнстрим ещё не заметил. Результат — дашборд на GitHub Pages.

Всё работает внутри GitHub: сбор, алгоритм отбора, разбор и сайт. Ничего не нужно держать
включённым на своём компьютере.

## Что он делает каждую неделю

```
arXiv · bioRxiv/medRxiv · GitHub · Hugging Face · Hacker News
        │  ~15–30 тыс. документов
        ▼
1. Извлечение терминов    1–3-словные фразы и теги («world model», «neural dust implant»)
2. Сравнение с историей   частота этой недели против базовой линии за 8 недель
3. Оценка «ранности»      рост · ускорение · разные типы источников · активность строителей
4. Глубокая проверка      топ-40: сколько пишут СМИ (GDELT) + «тест игрушки» по комментариям HN
5. Своя нейросеть         Qwen3-4B прямо в GitHub Actions: отсеивает шум, пишет разбор по-русски
6. Подборка               7 ранних сигналов + 2 «вне пузыря» + «уже волна» для сверки
        ▼
Дашборд на GitHub Pages + история в data/
```

### Из чего складывается балл «ранности» (0–100)

| Компонент | Смысл | Вес |
|---|---|---|
| Рост частоты | во сколько раз чаще в статьях и коде, чем по базовой линии | 0,20 |
| Фокус | доля работ, где термин в заголовке: им занимаются, а не упоминают вскользь | 0,14 |
| Ускорение | растёт ли сам рост | 0,12 |
| Разные типы источников | виден ли сразу в статьях, коде и обсуждениях | 0,12 |
| Активность строителей | звёзды GitHub в сутки, тренды Hugging Face | 0,12 |
| Разрыв со СМИ | строители уже тут, новости ещё молчат | 0,12 |
| Новизна | насколько недавно термин вообще появился | 0,10 |
| «Тест игрушки» | одновременно «это бесполезная игрушка» и «я не сплю третью ночь» | 0,08 |

До оценки работают фильтры от шума: обычные английские слова-одиночки («journey»), случайные сочетания
частых слов («single machine»), термины, которые ни разу не стоят в заголовках, и всплески только в
обсуждениях (новости про CEO, сбои, скандалы) в кандидаты не попадают.

Термины, которые уже большие (ожидалось больше 60 упоминаний в неделю), в ранние сигналы не попадают:
они уходят во вкладку «Уже волна».

У каждого сигнала есть две оценки: **«Заработать»** (можно ли за год превратить в продукт или доход)
и **«Научиться»** (выгодно ли стать в этом экспертом заранее). Кроме них — «ставка на выходные»
(дешёвая проверка гипотезы за 1–2 дня) и «критерий смерти» (когда сигнал можно бросить).

### Анти-пузырь

Два слота в каждом выпуске **принудительно** отданы сильным сигналам из областей, далёких от ваших
интересов (материаловедение, химия, энергетика, экономика…). Без этого ваши же 👍 через пару месяцев
замкнули бы радар в новый пузырь.

## Установка (10 минут, один раз)

1. **Создайте репозиторий** на GitHub (например, `signal-radar`). Можно приватный, но тогда Pages
   работают только на платных тарифах. С публичным всё бесплатно.
2. **Загрузите файлы:** Add file → Upload files → перетащите содержимое этой папки целиком
   (вместе со скрытой папкой `.github`) → Commit.
3. **Включите Pages:** Settings → Pages → Source: **GitHub Actions**.
4. **Первый запуск:** Actions → radar → Run workflow. Первый прогон идёт дольше (~1,5–2 часа):
   радар догружает 6 недель истории, скачивает нейросеть (~2,5 ГБ, дальше берётся из кэша)
   и прогоняет бэктест. Дальше он запускается сам
   **каждый понедельник в 07:17 по Стамбулу**.

Адрес дашборда появится в Settings → Pages (вида `https://<ваш-логин>.github.io/signal-radar/`).

## Своя нейросеть

Разбор делает небольшая открытая языковая модель **Qwen3-4B-Instruct** (2,5 ГБ, квантованная),
которая запускается прямо в GitHub Actions на обычном процессоре через llama.cpp. Никаких ключей,
API и оплаты: GitHub даёт публичным репозиториям бесплатные минуты, а модель скачивается
с Hugging Face один раз и дальше лежит в кэше.

Что она делает:
- **Фильтр.** По каждому из ~40 кандидатов отвечает: что это, к какому типу относится
  (технология, новые данные, устоявшаяся область, шаблонная фраза, имя или новость) и новое ли это.
  Остаются только новые технологии и новые научные данные. Сначала модель объясняет, потом
  решает, потому что так маленькие модели ошибаются реже.
- **Разбор.** Для 9 отобранных сигналов пишет «что это», «почему сейчас», «ставку на выходные»,
  «критерий смерти», оценки «Заработать» и «Научиться». Опирается только на цифры и аннотации
  из данных: ей прямо запрещено выдумывать.
- **Сводка недели** в 2–3 предложениях.

Честно про качество: это маленькая модель, а не Claude. Явный шум (шаблонные фразы, старые
области) она отсеивает хорошо, на пограничных терминах иногда ошибается в обе стороны. Для этого
есть вкладка «Отсеяно» и `tracker.yaml`. Модель меняется одной строкой в `config.yaml`
(например, на `unsloth/Qwen3.5-4B-GGUF`), если появится лучше.

## Как с ним работать

- **Обратная связь — файл `tracker.yaml`.** Отмечайте сигналы: `наблюдаю`, `ставлю`, `сработал`,
  `мёртв` (мёртвые больше не показываются), оценка `"+"` поднимает похожие сигналы.
  Через полгода по трекеру будет видно, что радар поймал рано, а что оказалось шумом.
- **Настройки — `config.yaml`.** Там ваш профиль (его видит аналитик), категории arXiv,
  интересы, веса алгоритма, размер подборки. Всё редактируется прямо на GitHub (иконка карандаша).
- **Вкладка «Проверка на прошлом»** показывает, загорелось бы правило радара на диффузионных
  моделях, LLM, трансформерах, агентах и NeRF раньше хайпа. Чтобы добавить свои волны,
  допишите их в `backtest:` в конфиге.

## Локально (необязательно)

```bash
pip install -r requirements.txt
python -m pytest -q             # проверки алгоритма
python -m radar run             # недельный прогон
python -m radar build           # дашборд в site/index.html
python -m radar backtest        # бэктест
```

## Честные ограничения

- Первые 3–4 недели база истории короткая, поэтому сигналы шумнее. Точность растёт с каждой неделей.
- Hugging Face не отдаёт исторические срезы, поэтому для роста он начинает работать через пару недель.
- Бэктест проверяет только канал статей (у GitHub и HN нет таких длинных исторических срезов).
  Это нижняя граница того, насколько рано радар мог бы заметить волну.
- GDELT (медиа-фон) иногда отказывает по лимитам. Тогда «разрыв со СМИ» считается нейтральным.
- Радар находит **кандидатов**, а не ответы. Решение принимаете вы, и для этого есть «ставка на выходные».
